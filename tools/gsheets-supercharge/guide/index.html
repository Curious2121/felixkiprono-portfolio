Gsheets SuperCharge guide

Take a messy dataset, clean and organize it, summarize it and create professional visualizations without leaving your Google Sheets workspace.

Getting started

  1. Open your spreadsheet and choose Extensions → Gsheets SuperCharge → Open. Authorize the requested permissions when prompted.
  2. Select the source sheet and the row containing its column headings. Changing the header row updates the dataset used by the tabs.
  3. Use Overview to understand the data, Records to browse and edit, Analysis to summarize and visualize, and Data Cleaning to repair or reshape it.

The maximized window provides more room. Minimize opens the compact workspace; Maximize returns to the larger workspace without intentionally resetting your active chart. Hover over controls for tooltips explaining their purpose. Keep a backup before bulk edits or deletion.

Overview: understand your dataset

Check row count, column count and average fill. The column table shows detected types, entries and completeness. Expand a column using its arrow to inspect values and distributions, or explore its analysis. The rotating charts provide a quick glimpse of your data; use previous, next and pause controls to navigate.

Change a column type when detection does not match its meaning. For example, a year used as a category can be Text rather than Number. Category changes can manage allowed options; data validation is written only through explicit category/option actions, not simply by opening the add-on.

Records: browse, select and edit

Visible fields controls which columns appear. Type badges identify Text, Date, Number and Category. Source row numbers help locate records in the sheet. Resize column headers to adjust widths; long values truncate when the column is narrow.

  1. Search or filter to find relevant records.
  2. Select individual checkboxes or All to select the matching dataset, including records not yet rendered in the scrolling list. Action counts refer to selected records, not simply the search-result count.
  3. Use New to add a record, or Open on a record to edit it. Save commits the edit while retaining the record form.
  4. Standardize, Export or Delete acts on the selected records. Review selection counts before bulk actions and confirm deletion carefully.

The hover Filter action filters by the exact value in that column. Search and selection are different: finding 100 records does not mean all 100 are selected.

Search and filter

Enter values in the search box and choose the column to filter, or use All columns. Matching-value pickers let you select multiple values. Date pickers expand hierarchically by year, month and date.

When applying another filter, choose Stack to keep existing filters and narrow their combined result, or Replace to begin with the new filter instead. Applied-filter chips show the current conditions; remove one using its × or use Clear all. Analysis shows the same filter information above the chart, including any Largest/Smallest limit.

Records filters and Analysis filters have separate contexts. Create Chart from Records carries the relevant filtering workflow into Analysis. Always check the displayed filter summary before exporting.

Analysis: summarize without building a pivot manually

  1. Choose data and apply any filters.
  2. Choose a chart type: column, bar, line, area, stacked variants, pie or doughnut.
  3. Under Fields to visualize, choose the X-axis category and Y-axis measure. Choose an aggregation such as Sum or Count rows.
  4. Use a series/breakdown field to compare groups. Group dates or numeric values when appropriate, and choose the X-group sort order.
  5. Leave Limit blank for all categories, or enter a number with Largest or Smallest. Enter 10 to focus on ten groups when a chart has too many categories.

The Chart and Table tabs live inside the visualization section. Chart shows the visualization; Table shows the summary data powering it. The table is useful for checking totals and investigating why a chart looks the way it does.

Full View enlarges the chart workspace. Use the side-panel arrows to access setup or customization; only one side panel is expanded at a time. The chart orientation applies to the preview as well as image exports. In compact mode use Choose Data, Chart Setup and Customize above the chart.

Customize the chart

Click a chart element to select it and navigate to its corresponding customization controls. Click unused chart space to select the background. The selection outline is an editing aid, not part of the exported design.

Save analyses and export

Open Save & Export to choose an output. Premium access is required for exports and hiding attribution under the current product model.

  • Save analysis: store a reusable analysis, including its chart configuration. Open a saved entry by its name or Open button. A saved snapshot can be viewed without recalculating; changing its data selections refreshes from the source.
  • Save to sheet: create a native Google Sheets summary/pivot and supported native chart. Native charts remain editable in Sheets and can be linked into Google Docs or Slides. Native rendering can differ from the add-on renderer.
  • PNG: a raster image for presentations and publications.
  • SVG: a scalable graphic.
  • Copy HTML code: interactive chart code for a page that permits embedded HTML and scripts. Some blogging platforms restrict scripts; check the platform before publishing.

Default export names follow series-value-chart. Check the filters and category limit before saving. A fresh add-on restart resets working colour choices and clears the Largest/Smallest limit; opening a saved analysis restores its saved settings. Minimize/Maximize is not a fresh restart. Changing underlying data clears the category limit so an old limit does not silently constrain a new analysis.

Data Cleaning

Duplicates

Choose one sheet and the columns defining a duplicate. Preview the groups/counts first. Select duplicates in Records for inspection, or confirm removal while retaining the first occurrence. Duplicate checking is single-sheet, not an all-sheets operation.

Find and replace

Select the sheet searched and relevant column scope, enter the value to find and replacement, then Preview. Use the empty/null option for blank cells. Review matching cells and the sheet name before Replace matches. Where offered, All sheets broadens this workflow; it is not available for duplicate checking.

Unpivot

Use this when repeated categories are spread across separate columns, such as one column per year. Choose the source, identifier columns to retain and value columns to turn into rows, then review the proposed output before confirming. The resulting long-format table is easier to summarize and visualize.

Sanitation and standardization

Use the available sanitation/standardization actions to normalize inconsistent values. Read each tooltip and preview where offered; these are data-changing operations, not merely chart formatting.

Help, trial and troubleshooting

Help contains quick tips, product information and support links. The Premium trial lasts 60 days. Upgrade or Request extension from the subscription area; use the extension form to explain what you need.

  • If results look wrong, verify the source sheet, header row, column types and applied filters.
  • If no series plots, check the included-series list and that the selected measure contains usable values.
  • If the Table has data but the Chart does not, try a simpler chart configuration and report the setup to support.
  • Wait for processing indicators before repeating an operation. For authorization/session problems, test with one Google account signed in.
  • After changing sheet data, refresh the relevant view so its summary reflects the source.
